# ربات انتشار خودکار پروژه‌های گیت‌هاب در کانال تلگرام

هر پروژه‌ی جدیدی که در گیت‌هاب (`keyvan-alavi`) بسازید، خودکار با توضیحات، بخشی از README و لینک در کانال `@technokey1` منتشر می‌شود.
هر وقت برای پروژه‌ای **Release** جدید بسازید، پست «آپدیت جدید، نسخه فلان» همراه لینک منتشر می‌شود.

## راه‌اندازی (یک بار، حدود ۱۰ دقیقه)

### ۱) ساخت ربات تلگرام
1. در تلگرام به `@BotFather` پیام بدهید و دستور `/newbot` را بفرستید.
2. نام و یوزرنیم ربات را انتخاب کنید و **توکن** را کپی کنید (چیزی شبیه `123456:ABC...`).
3. توکن را جایی منتشر نکنید و برای کسی نفرستید.

### ۲) ادمین کردن ربات در کانال
کانال `technokey1` ← Administrators ← Add Admin ← ربات را جستجو و اضافه کنید ← دسترسی **Post Messages** فعال باشد.

### ۳) ساخت ریپازیتوری ربات در گیت‌هاب
1. یک ریپازیتوری جدید بسازید، مثلاً با نام `telegram-notifier` (می‌تواند Private باشد).
2. این سه چیز را داخلش بگذارید:
   - `bot.py` در ریشه
   - `.github/workflows/notify.yml` (دقیقاً با همین مسیر)
   - `README.md` (همین فایل، اختیاری)

### ۴) ذخیره توکن
در ریپازیتوری ربات: **Settings ← Secrets and variables ← Actions ← New repository secret**
- Name: `TELEGRAM_BOT_TOKEN`
- Secret: توکنی که از BotFather گرفتید

### ۵) اولین اجرا
تب **Actions** ← workflow به نام *Telegram Notifier* ← **Run workflow**.
اجرای اول **همه‌ی پروژه‌های قدیمی شما را** از قدیمی به جدید در کانال منتشر می‌کند (بین هر پست چند ثانیه فاصله است، پس برای ۴۰ پروژه حدود ۳ تا ۵ دقیقه طول می‌کشد). از آن به بعد فقط پروژه‌ها و ریلیزهای جدید منتشر می‌شوند.

## کارکرد روزمره
| کار شما در گیت‌هاب | کار ربات در کانال |
|---|---|
| ساخت ریپازیتوری جدید + README | پست معرفی: عنوان، توضیح، خلاصه README، لینک پروژه، دکمه |
| ساخت Release جدید (مثلاً `v1.2`) | پست آپدیت: «نسخه v1.2 اعمال شد» + تغییرات + لینک دریافت |

ربات هر ۱۵ دقیقه چک می‌کند؛ پس پست ممکن است تا ۱۵ دقیقه بعد بیاید.

## نکات
- **پروژه‌ی قدیمی را دستی منتشر کنید:** Actions ← Run workflow ← در `force_repo` نام ریپازیتوری را بنویسید.
- **اگر نمی‌خواهید پروژه‌های قدیمی منتقل شوند:** در اجرای اول `post_existing` را `false` بگذارید تا فقط بی‌صدا ثبت شوند.
- **آپدیت با هر کامیت:** در `notify.yml` مقدار `UPDATE_MODE` را از `releases` به `commits` تغییر دهید. توصیه نمی‌شود، چون با هر کامیت کوچک پست می‌آید.
- فورک‌ها و ریپازیتوری‌های آرشیوشده نادیده گرفته می‌شوند.
- پروژه‌های Private در لیست عمومی گیت‌هاب نیستند و ربات آن‌ها را نمی‌بیند (و نباید هم در کانال عمومی بیایند).
- برای ساختن Release: صفحه ریپازیتوری ← Releases ← Draft a new release ← تگ (مثل `v1.2`) و توضیح تغییرات را بنویسید ← Publish.
- اگر بیش از ۶۰ روز هیچ فعالیتی در ریپازیتوری ربات نباشد، گیت‌هاب اجرای زمان‌بندی‌شده را متوقف می‌کند؛ ولی چون ربات خودش `state.json` را کامیت می‌کند، معمولاً مشکلی پیش نمی‌آید. اگر متوقف شد، یک بار دستی Run workflow بزنید.
